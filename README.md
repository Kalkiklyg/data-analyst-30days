# Data Analyst — 30 Days Practice (Python + SQL)

This repository captures a 19-day practice sprint for Python and SQL focused on data-analysis tasks:
- Python: strings, lists, sets, dicts, functions, classes, regex, pandas (transactions).
- SQL: joins, aggregation, subqueries, window functions (RANK/DENSE_RANK).

## Structure
- `python/` — Jupyter notebooks (day01 → day19). Each notebook is focused and runnable.
- `sql/` — SQL files with queries grouped by topic.
- `data/` — (optional) sample datasets: `feedback.txt`, `transactions.csv`.
